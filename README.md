# Weatherly

A lightweight weather dashboard built with plain HTML, CSS, and JavaScript.

## Features

- Search by city name
- Use browser geolocation for local weather
- Current temperature, humidity, wind, sunrise, and sunset
- Hourly forecast for the next several hours
- 5-day weather outlook
- Responsive layout for desktop and mobile

## Run it locally

Open the file directly in your browser:

- [index.html](index.html)

Or serve the folder with any static file server, for example:

```bash
cd "c:\Users\HomePC\Desktop\WEATHER APP"
python -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

## Data source

The app uses the Open-Meteo API for geocoding and forecast data.
